Dockerized Website Deployment on AWS ECS Fargate

A cloud deployment project demonstrating containerization, serverless container hosting, automated CI/CD pipelines and centralized application logging using AWS.

View GitHub Repository ↗ Explore Architecture

01. Project Overview

This project demonstrates how to deploy a Dockerized static website on Amazon ECS using AWS Fargate. It also implements an automated CI/CD pipeline using GitHub Actions, allowing application updates to be deployed automatically whenever code is pushed to GitHub.

Containerization

Packaged a static website using Docker and the official Apache HTTP Server image.

Cloud Deployment

Hosted the Docker container using Amazon ECS with AWS Fargate.

Automation

Automated Docker image builds and ECS deployments through GitHub Actions.

03. Technologies Used

Docker

Containerized the website into a portable Docker image.

Amazon ECR

Private container image registry for storing Docker images.

Amazon ECS

Managed container orchestration and task deployments.

AWS Fargate

Serverless compute engine for running containers.

IAM & OIDC

Secure authentication and permissions for GitHub Actions.

CloudWatch

Centralized container log collection and inspection.

04. Deployment Workflow

The deployment process is automated using GitHub Actions. Every push to the main branch triggers the pipeline.

01. Code Push

Application changes are pushed to the GitHub main branch.

02. AWS Authentication

GitHub Actions assumes an IAM role using OpenID Connect (OIDC).

03. Docker Build

A new Docker image is built and tagged with the Git commit SHA.

04. Push to ECR

The new Docker image is uploaded to Amazon ECR.

05. ECS Deployment

The task definition is updated with the new image and deployed to Fargate.

06. CloudWatch Logging

Container logs are collected in Amazon CloudWatch Logs.

05. Key Learnings

  • Building and running Docker containers.
  • Working with private Amazon ECR repositories.
  • Deploying applications using ECS and Fargate.
  • Configuring IAM roles and OIDC authentication.
  • Building automated CI/CD pipelines.
  • Collecting and inspecting application logs using CloudWatch.
